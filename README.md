# ESP32 Barograph PC

> Репозиторий содержит только приложение для ПК. Прошивка автономного барографа на ESP32 хранится отдельно: [mikenilsonforeva-ux/Esp32-barograph](https://github.com/mikenilsonforeva-ux/Esp32-barograph) (Arduino IDE; подключение, установка и описание API — в её README). Для выгрузки CSV и периодов с SD-карты нужна прошивка **1.1.0 или новее**; на более старой приложение работает с буфером ОЗУ устройства.

Приложение для компьютера (Windows — целевая платформа, Ubuntu/Linux), которое работает с барографом на ESP32 по сети: показывает текущие значения и прогноз, **скачивает историю и хранит её в локальной базе SQLite**, строит графики за любой период, экспортирует данные в **CSV, Excel, SQLite, JSON, PNG**, меняет настройки устройства (Wi-Fi, периоды, время).

> **Что проверено.** Сетевой клиент, синхронизация без дублей, база, все форматы экспорта, графики и командная строка проверены автотестами (`tests/`) против имитатора устройства (`tools/mock_esp32.py`), который повторяет API прошивки. Логика окна (обработчики кнопок) прогнана с подменой tkinter; **в настоящем окне Tk (Windows/Ubuntu) и с реальным ESP32 приложение я не запускал** — в среде разработки нет графики и устройства. Если что-то в окне выглядит или работает не так, пришлите описание или скриншот.

## Установка и запуск

**Windows 10/11**
1. Установите Python 3.9+ с python.org (в установщике оставьте галочки «Add python.exe to PATH» и «tcl/tk and IDLE»).
2. Дважды щёлкните `run.bat`. При первом запуске он создаст окружение `.venv` и установит библиотеки (нужен интернет), затем откроет окно.

**Ubuntu**
```bash
sudo apt install python3-tk python3-venv
./run.sh
```
Вручную: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python barograph_app.py`.

**Один exe-файл для Windows** (необязательно): `build_exe.bat` → `dist\ESP32Barograph.exe`.

## Подключение к устройству

Вверху окна укажите адрес: `esp32-barograf.local` (по умолчанию) или IP из монитора порта (например `192.168.1.79`), порт 80. После первого успешного подключения приложение запоминает IP и использует его, если имя `.local` перестало находиться (в Windows mDNS-имена иногда не резолвятся — тогда просто введите IP). Если устройство в режиме точки доступа: подключите ПК к сети `ESP32_barograf` и введите `192.168.4.2`.

## Как хранятся данные

Устройство держит в ОЗУ последние 72 часа. Кнопка **«Синхронизировать историю»** (или автосинхронизация) скачивает их целиком (`/api/export.csv`, сырые записи без усреднения) и добавляет в локальную базу `barograph.db`; уже имеющиеся метки времени пропускаются, поэтому синхронизировать можно сколько угодно раз. **Чтобы не терять данные, синхронизируйтесь не реже одного раза в 72 часа** (автосинхронизация делает это сама, пока приложение запущено; для запуска «в фоне» есть консольная команда ниже). Полная история за периоды, когда ПК был выключен, лежит на SD-карте устройства — скачайте её на вкладке «Экспорт / импорт» (блок «Выгрузка CSV с устройства») или командой `download-csv --import`.

База — обычный SQLite:
```sql
readings(ts INTEGER PRIMARY KEY,   -- Unix время, UTC
         pressure REAL,            -- мм рт. ст.
         temperature REAL,         -- °C
         humidity REAL)            -- %, NULL для BMP280
meta(key, value)
```
Расположение по умолчанию: Windows — `%LOCALAPPDATA%\ESP32Barograph\barograph.db`, Linux — `~/.local/share/ESP32Barograph/barograph.db`; настройки — `%APPDATA%\ESP32Barograph\config.json` / `~/.config/ESP32Barograph/config.json`.

Время хранится в UTC, показывается в часовом поясе устройства (по умолчанию берётся у него, сейчас UTC+3); вручную поменять можно на вкладке «Приложение».

## Командная строка (без окна)

```
python barograph_app.py status | current | forecast | wifi-scan | set-time
python barograph_app.py sync [--loop 30]              # скачать историю; --loop - повторять каждые 30 мин
python barograph_app.py stats --hours 24
python barograph_app.py export --format xlsx --out data.xlsx --from 01.10.2026 --to 05.10.2026 --resample 1h
python barograph_app.py export --format csv --out data.csv --hours 72 --unit hPa --excel-csv
python barograph_app.py import-csv D:\barograph.csv
python barograph_app.py device-range                  # за какой период у устройства есть записи (/api/range)
python barograph_app.py download-csv --out full.csv   # весь CSV с SD-карты
python barograph_app.py download-csv --out oct.csv --from 01.10.2026 --to 31.10.2026 --import   # период, и в базу
python barograph_app.py stats --csv full.csv --hours 24                          # статистика по CSV-файлу
python barograph_app.py export --csv full.csv --format png --out g.png --from 01.10.2026 --to 05.10.2026   # график
python barograph_app.py settings --measure-interval 30 --record-interval 300
python barograph_app.py settings --ssid MyWiFi --password secret123
```
Общие параметры: `--host`, `--port`, `--db`. Форматы: `csv`, `xlsx`, `sqlite`, `json`, `png`. С `--csv ФАЙЛ` команды `stats` и `export` берут данные из файла, а не из базы (формат `sqlite` — только из базы).

**Регулярная синхронизация по расписанию.** Windows: Планировщик заданий → действие `C:\...\.venv\Scripts\python.exe C:\...\barograph_app.py sync`, повтор каждые 6 часов. Ubuntu (cron): `0 */6 * * * /путь/.venv/bin/python /путь/barograph_app.py sync`.

## Ограничения

- «Синхронизировать историю» берёт только буфер ОЗУ устройства (последние 72 часа). Всё, что старше, — через «Выгрузку CSV с устройства» (нужна SD-карта и прошивка 1.1.0+; без карты отдаётся тот же буфер ОЗУ).
- Файл с SD-карты за годы читается целиком в память (год с записью раз в минуту — файл ~25 МБ, около 100–200 МБ ОЗУ и порядка секунды чтения); для очень длинных периодов скачивайте нужный диапазон.
- Excel не принимает больше ~1 млн строк: для длинных периодов выберите усреднение.
- Значок прогноза — символ Юникода; вид зависит от шрифтов системы.
- Авторизации в API прошивки нет: используйте только в доверенной локальной сети.
